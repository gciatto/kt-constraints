# API reference

The KDoc of every published module is generated by Dokka and served with this site:
**[open the API reference](/kt-constraints/api/index.html)**.

It covers the Kotlin common, JVM, JS and Native source sets of each module. Java and TypeScript users can read it
alongside the [Java API](java-api.md) and [TypeScript API](typescript-api.md) pages, which describe the facades
those languages see.
