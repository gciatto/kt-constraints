# M2 — Resource-safe solving and the first real route

Implemented incrementally on `develop` with JVM-only TDD iterations and separate test/implementation commits.
The implementation plan remains untracked. The public API is experimental.

## Delivered

- Exact immutable assignments, route-scoped descriptors, support reports and explicit backend registration.
  Selection checks capabilities, runtime availability and the whole model; it never instantiates test fakes.
- Independent search status and termination reasons, exact objective/bound values, immutable messages/statistics,
  and validation that incomplete search cannot claim optimality or infeasibility.
- Single-consumer solution streams with one definitive completion event, concurrent cancellation, coroutine
  cancellation propagation, idempotent close and exactly-once resource release. Solvers own their active streams.
- Solver-independent typed valuation for pure expression checking. Undefined element indices are distinguishable
  from unsupported-node errors; assignments are validated before projecting public variables.
- An unpublished exact finite oracle capped at 10,000 candidates and 64 variables. Satisfaction output is deduplicated
  after projection; optimization output contains improving incumbents. Unsupported constructs fail before search.
- Shared solver contracts for SAT/UNSAT, min/max, independent assignment validity, enumeration/projection,
  timeout/limits, cancellation/close and unsupported models. Oracle and real Gecode reuse the same contracts.
- A portable checked MiniZinc compiler and JSON decoder, plus JVM Gecode execution through an installed CLI.
  The route ID is `gecode/minizinc`; direct engines and other MiniZinc engines are separate future routes.
- A manual phase benchmark, a dedicated real-runtime CI job, and an expanded portable Native contract matrix.

## Runtime and numeric semantics

`MiniZincGecodeBackend(executable)` discovers Gecode and proves runtime availability with a tiny real solve.
The compiler preserves globals until MiniZinc lowering and emits internal names independent of user labels.
Every integer intermediate must fit [Gecode's documented limits](https://www.gecode.org/doc-latest/reference/gecode_2int_8hh_source),
`-2147483646..2147483646`; uncertain or oversized bounds are rejected, never truncated.

Full decoded assignments are independently checked against the original constraints and objective before public
projection. A successful process exit and definitive status are required before returning proof statuses.
Malformed output, contradictory output and process failures cannot become UNSAT. Runtime messages and raw JSON
statistics are retained at successful process completion; interrupted runs retain their published incumbent.

Processes, child processes, output executors, deadline executors and temporary files belong to the stream.
Regression tests cover close during a read, caller cancellation, cleanup failures, a late producer result,
real process-tree cleanup and long-deadline timer cleanup. The timer leak was observed as a failing real-runtime
test before the fix. Cancellation and timeout preserve the first definitive terminal result.

## Validation

Development used JDK 21 on macOS arm64. Real tests used the official MiniZinc 2.10.1 ARM Mac bundle and Gecode
6.4.0, installed only in temporary storage; its release SHA-256 was verified before execution.

| Check | Result |
|---|---|
| JVM TDD iterations | Passed, after observed missing-API and runtime regressions |
| Milestone `jvmTest jsTest --parallel --continue` | 140 JVM and 124 JS leaves passed; zero skipped |
| Real MiniZinc JVM module | 23 leaves passed, including shared conformance and actual cleanup/deadline tests |
| `ktlintFormat`, then `ktlintCheck detektAll --parallel --continue` | Passed; two compiler-proven analyzer exceptions described below |
| One top-level type per production file | Verified across all touched modules |
| Manual phase benchmark | Three measured samples; exact-result self-check passed |
| `check --parallel --continue` | Failed only at 14 Apple Native link tasks due to missing full Xcode |
| `check` excluding those Apple test tasks | Passed; no repository test task was disabled |
| Documentation site | Built successfully with MkDocs Material |
| Ten regenerated JVM/common POMs | Expected coordinates; no runtime test-utility, Kotest or 2p-Kt dependency leaks |

Run real tests with:

```bash
MINIZINC_EXECUTABLE=/path/to/minizinc ./gradlew :solve-minizinc:jvmTest
```

Without that variable the real-runtime spec is explicitly skipped; compiler and protocol tests still execute.
CI installs MiniZinc/Gecode on Ubuntu and sets the variable, so an unavailable requested runtime fails the job.
Portable Native CI includes `core`, `model`, `dsl`, `solve`, `solve-spi`, `test-solve` and the portable MiniZinc code.

The 14 local link failures are `iosSimulatorArm64Test` and `macosArm64Test` dependencies in each of those seven
modules. They report `MissingXcodeException` from `xcrun xcodebuild -version`; this machine has Command Line Tools
but no full Xcode. Native compilation is exercised, but local Native execution is not claimed. The restricted
check explicitly excludes only those 14 test tasks, with normal JVM/JS and real Gecode tests still enabled.
Explicit runtime tests disable both up-to-date and build-cache reuse, so a prior runtime-free skip cannot masquerade
as a real integration pass.

Detekt 1.23.8 incorrectly labels two required suspend helpers as redundant. Removing each modifier was separately
verified to fail Kotlin compilation at its coroutine calls. Those two exact findings have documented local exceptions;
other findings were fixed directly, and Kotlin compiler warnings remain errors.

## Boundaries

Only Gecode via MiniZinc on JVM executes real models today. MiniZinc JS/Wasm, Native process transports,
other MiniZinc engine catalogues, direct engines, incremental sessions, native propagation and stable Java/TS
facades are not implemented. Backend publishing remains disabled, and no release gate was enabled.
M3 next expands installed-engine discovery, differential coverage and MiniZinc platform transports.
